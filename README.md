# Sai Santhosh Kumar Perumal — AI & Data Engineering Portfolio

Interactive portfolio focused on **Graph RAG, Generative AI, agentic retrieval, NLP sentiment intelligence, graph ML, and cloud data engineering**.

## Live portfolio

The repository includes a static interactive `index.html` designed for GitHub Pages and an executable Streamlit version in `portfolio_app.py`.

### Featured projects

- **Enterprise Graph RAG Knowledge Assistant** — vector, graph, and hybrid retrieval; evidence paths; retrieval evaluation.
- **Sentiment Intelligence** — competitor NLP, aspect sentiment, themes, model evaluation, and live prediction.
- **Multi-Agent RAG** — Retriever → Generator → Validator execution trace.
- **GNN Node Classification** — interactive graph-learning metrics and architecture.
- **Data Engineering Architecture** — AWS/GCP, ETL/ELT, Spark, Airflow, Snowflake, BigQuery, Terraform, Docker, Kubernetes, and MLflow.

## Streamlit version

```bash
pip install -r requirements.txt
streamlit run portfolio_app.py
```

The static GitHub Pages version requires no Python installation.

## Result integrity

Portfolio demo metrics are deterministic presentation/evaluation examples unless explicitly identified as production measurements. Cloud-backed Azure OpenAI, Neo4j, and hosted-model integrations require credentials configured outside source control.
